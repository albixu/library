# HU-020: Migración de Angular Material a TailwindCSS

## 📋 Descripción

Migrar el web client de Angular Material a HTML nativo + TailwindCSS para lograr alineamiento pixel-perfect con los diseños de Stitch y tener control total sobre el estilo de la aplicación.

## 🎯 Objetivos

- Eliminar Angular Material (excepto CDK para overlays)
- Implementar diseño exacto de Stitch con TailwindCSS
- Reducir bundle size en ~500KB (~40%)
- Mantener 80%+ cobertura de tests
- Mejorar mantenibilidad del código
