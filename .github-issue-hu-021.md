# HU-021: Optimización de Consolidación y Separación de Modelos de IA

## 📋 Descripción

Migrar la arquitectura de los dockers asociados a los modelos locales LLM. Desvincular el script principal central `consolidate-books.ts` de una base de datos de Postgres y separarlo hacia deduplicación in-memory de colecciones JSON. A su vez aislar la traducción del proceso usando `aya-expanse:8b` y separar los procesos de Inferencia global en dos dockers local separados: `ollama-embeddings` y `ollama-translations`.

## 🎯 Objetivos

- Remover queries de control de isbns en BD del script de consolidacion.
- Optimizar consumo e iteración eliminando DB local al consolidar datos JSON.
- Actualizar `qwen2.5:1.5b` a `aya-expanse:8b`.
- Aislar dockers y redes locales sobre inyecciones de `Fastify` Environment.
- Reforzar el coverage del refactor `vitest`.
